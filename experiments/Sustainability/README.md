# experiments / Sustainability

Exploratory work for the **Sustainability** sub-index: analysing missingness and
benchmarking imputation before the clean versions moved to
`src/sustainability/`.

## Notebooks
- `Missing tables.ipynb` — maps missing values across the environmental
  indicators (emissions, renewables, air pollution).
- `model_testing.ipynb` — benchmarks imputation-method accuracy (MICE vs RFR) on
  synthetic missingness.

Research-quality notebooks; the production pipeline is in `src/sustainability/`.
