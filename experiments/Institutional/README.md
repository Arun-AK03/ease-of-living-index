# experiments / Institutional

Exploratory work for the **Institutional** sub-index: benchmarking imputation
and prototyping the index before the clean versions moved to
`src/institutional/`.

## Notebooks
- `Missing tables.ipynb` — maps missing values across the governance indicators.
- `MICE_model_testing.ipynb` — benchmarks MICE imputation accuracy on synthetic
  missingness.
- `Institutional_Index.ipynb` — an early end-to-end prototype of the
  institutional index.

Research-quality notebooks; the production pipeline is in `src/institutional/`.
