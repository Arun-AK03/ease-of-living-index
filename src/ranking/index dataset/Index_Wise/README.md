# src / ranking / index dataset / Index_Wise

Rankings sliced **by index**. One file per dimension, each spanning all
available years, so you can follow a single measure over time.

## Files
- `Economic_Rank_All_Years.csv`
- `Institutional_Rank_All_Years.csv`
- `Quality_of_Life_Rank_All_Years.csv`
- `Sustainability_Rank_All_Years.csv`
- `Ease_of_Living_Rank_All_Years.csv` — the overall composite rank

Each file has `Year`, `Country`, and the single rank column for that index.
For the complementary "all indices, one year" view see `../Year_Wise/`.
